Frequently asked questions

Everything you need to know before you sign up.
What's the difference between a User and an Administrator account?

User accounts handle attendee registration, view events, and manage their own schedule, past events, feedback and incident reports. Administrator accounts create events and run the full planning suite: check-in, venues, speakers, scheduling, sponsors, incident management, and operations.

Do attendees need an account to register for an event?

No — attendee registration is handled by your signed-in team through the Registration page. Attendees themselves don't need a Checkpoint account; they receive a QR ticket once registered.

How does duplicate registration prevention work?

Every registration is checked against existing attendees for that event by email and phone number before it's saved, so the same person can't end up with two tickets.

How do the Venue and Speaker Agents make recommendations?

Each agent scores available options against your stated requirements — things like capacity, budget, facilities, topic relevance and availability — and returns a ranked list with a transparent point breakdown, not a black-box answer.

What happens when an incident is reported?

The Incident Agent immediately computes a priority level and urgency score from its severity and type, and automatically escalates it if it crosses a time or severity threshold — priorities keep updating in real time while an incident stays open.

Can I upgrade a user account to admin later?

Not from within the app yet — account type is chosen at sign-up for now. Reach out via the contact section below if you need an account's role changed.
